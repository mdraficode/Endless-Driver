# Runtime assets

No third-party models, textures, sounds, or environments have been acquired for this scaffold.

- `models/`: approved GLB/GLTF models and sidecar resources.
- `textures/`: approved material maps; optimized formats when supported.
- `audio/`: approved engine and environment sound, if later authorized.
- `environments/`: approved sky/IBL data.
- `manifest.json`: versioned inventory; currently empty.

Read [the asset policy](../../docs/ASSET_POLICY.md) before adding files. Keep URLs relative to the deployment base. Track large assets with Git LFS only after installation, repository support, and quotas are verified; no LFS filters are enabled yet.
